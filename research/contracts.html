Before using these

  • These are samples, not legal advice. Have each one reviewed by a lawyer in the country where it will be signed. Employment rules on probation, notice, leave, end-of-service pay and restrictions after employment differ a lot between countries.
  • The text is country-neutral, like the website. Governing law, courts, currency and statutory entitlements are left as placeholders.
  • Client contracts match the product as it is today: monthly payroll, a bank payment file rather than sending payments, no tax filing, and the security controls listed on the Security page. Update them when that changes.
  • Check the DPA's Annex 2 and Annex 3 (security measures and sub-processors) with engineering before sending it to a customer.
  • To change the wording, edit research/contracts/src/contracts.py and run python3 research/contracts/src/build_contracts.py. It rebuilds every PDF, Word file and preview, and this page (needs Google Chrome on a Mac and python-docx).
